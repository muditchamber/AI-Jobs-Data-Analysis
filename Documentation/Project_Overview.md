# AI Jobs Data Analysis

## Project Overview

This project analyzes an AI Jobs dataset to identify trends and insights related to AI-related job opportunities.

The analysis was performed using Microsoft Excel, including data cleaning, pivot tables, charts, and dashboard development.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Cleaning
- Data Analysis
- Dashboard

## Project Workflow

1. Raw data collection
2. Data cleaning and preparation
3. Exploratory analysis
4. Pivot table analysis
5. Chart creation
6. Executive summary
7. Interactive dashboard

## Key Analysis Areas

- AI job opportunities
- Job-related trends
- Salary-related analysis
- Job categories
- Location-based analysis
- Other relevant patterns in the dataset
